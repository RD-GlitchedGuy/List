# Custom maps

Add custom map JSON files here, named for their destination:
`bedwars.json`, `skywars.json`, `oneblock.json`, `buildbattle.json`, or
`dropper.json`. The single-player world list exports full `.skycraft` world
files; it does not export minigame map files. Rebuild SkyCraft for custom maps
to be included. A map file can include `spawns` to override team spawns.
